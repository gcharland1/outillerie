# General guidance for UI

## Butons
1. Butons should be buttons (Have an outline and a background color)
2. A link should not be used as a button unless in a text. If in a menu or an action context, actions should be done through buttons.
2. Dangerous actions (Like delete) should have red tint to them

## Layout

1. All elements should have a standard minimum gap (either padding or margin) to prevent 2 elements from being stuck together
2. The top menu should be clearly outlined
3. All personnal contexts (like "Gérer mes outils", an eventual "Mon profil", eventual "Préférences) should be hidden inside a "hamburger"
   menu next to the user's id
   opened by clicking the username
